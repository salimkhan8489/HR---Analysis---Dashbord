# HR Analysis Dashboard | Power BI

## 📌 Project Overview

The HR Analysis Dashboard is an interactive data visualization project developed using Microsoft Power BI to analyze employee data and understand workforce trends. The project focuses on employee demographics, attrition, and workforce distribution to help HR teams make data-driven decisions.

The dashboard provides a clear overview of key HR metrics and helps identify patterns in employee turnover across different departments, age groups, genders, job roles, and experience levels.

## 🎯 Project Objectives

- Analyze employee demographics and workforce distribution.
- Monitor employee attrition and retention trends.
- Identify departments and job roles with higher employee turnover.
- Track key HR performance indicators (KPIs).
- Provide meaningful insights to support HR decision-making.

## 🛠️ Tools and Technologies

- **Microsoft Power BI:** Dashboard development and data visualization.
- **Power Query:** Data cleaning and transformation.
- **DAX:** KPI calculations and measures.
- **Microsoft Excel:** Data storage and preliminary analysis.

## 📊 Key Performance Indicators (KPIs)

| KPI | Description |
|---|---|
| Total Employees | Total number of employees in the dataset. |
| Active Employees | Number of employees currently working in the organization. |
| Attrition Count | Number of employees who have left the organization. |
| Attrition Rate | Percentage of employees who have left the organization. |
| Average Age | Average age of employees. |
| Average Tenure | Average length of employee service. |

*Note: The exact KPI definitions and calculations depend on the dataset and the measures implemented in the dashboard.*

## 📈 Dashboard Analysis

### 1. Employee Demographics
Analyzes employee distribution by gender, age group, and other demographic categories to understand the workforce composition.

### 2. Department-Wise Analysis
Compares employee distribution and attrition across departments to identify areas that may require further investigation.

### 3. Job Role Analysis
Examines workforce distribution and attrition across different job roles to identify employee turnover patterns.

### 4. Age Group Analysis
Analyzes employee counts and attrition across different age groups to understand workforce trends.

### 5. Experience and Tenure Analysis
Studies employee experience and service duration to understand retention patterns.

## 💡 Business Value

- Helps HR teams monitor workforce trends.
- Supports the identification of potential employee retention challenges.
- Enables comparisons across departments and job roles.
- Improves visibility into important HR metrics.
- Supports data-driven workforce planning.

## ⚙️ Project Workflow

1. Imported employee data from Excel into Power BI.
2. Cleaned and transformed the data using Power Query.
3. Created DAX measures for relevant HR KPIs.
4. Developed charts and visualizations to analyze employee data.
5. Added interactive filters and slicers for detailed analysis.
6. Built an interactive dashboard to present HR insights.
